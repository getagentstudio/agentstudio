# Worktree fork: behavior baseline and Linux counterpart contract gaps

A Linux fork counterpart includes a usable Git worktree, its branch and index effects, intentional copy differences, and the outcome of cleanup. Successful file cloning alone does not cover that behavior. The selected obligation is [U5/U6/U11](../../../user-requirements.md:28), expressed by the Specification's [R2/R4 and C2/V2](../../../2026-10-15-agentstudio-daemon.md:120).

This worksheet separates the current Mac package behavior from the unresolved target contract. Current behavior is evidence to preserve or deliberately change; it does not silently select a Linux filesystem profile, a shared native/CLI policy, a wire schema or a backend. The complete system retains the [required frontend route](../../../2026-10-15-agentstudio-daemon.md:119).

## Current inputs and meaning

The source baseline is AgentStudio `624300332f5e50f7bb8cbb9fc786d5e5b4a3d462` and its Git package pin `4cca397dfc869857064da4e9ec8289ea46adc479`. These are source observations, not executed results.

Rows distinguish declared contracts from inspected call boundaries. Invoking a validator, metadata copier or filter does not independently establish all of its delegated predicates. The [bounded package evidence](../../../research/evidence/2026-10-15-daemon-extraction-survey/fork-package-contract-evidence.md) names those transitive source gaps; complete helper semantics and runtime parity are not established by this worksheet.

## Current success and failure boundaries

| Boundary | Current observable distinction | Consequence for the counterpart contract |
| --- | --- | --- |
| Git usability | The writer creates a linked worktree, materializes/re-homes Git administration, builds indexes, validates, attaches the branch target and validates attachment before returning the worktree plus materialization evidence. [Writer](../../../../../../../agentstudio-git/Sources/AgentStudioGitLocal/WorktreeFork/LibGit2WorktreeForkWriter.swift:49). | Cover Git administration, index/HEAD/branch and nested-repository behavior in addition to file contents. A directory or a clone count does not establish the complete result. |
| Intentional copy differences | CoW success reports counts plus skipped/normalized entries, ignored exclusions, nested worktree exclusions, source-state and submodule/LFS information. A skipped entry is absent; a normalized entry exists with reported metadata loss. [Report](../../../../../../../agentstudio-git/Sources/AgentStudioGitContracts/GitWorktreeForkContracts.swift:280). | Define admitted differences and their result evidence explicitly. “Successful fork” is not universal byte/metadata equality. |
| Node and metadata policy | The public vocabulary distinguishes directories, files, symlinks, FIFOs, sockets and device/unknown kinds. It reports non-reproduced socket endpoints and selected owner/set-ID normalization reasons. [Kinds/reasons](../../../../../../../agentstudio-git/Sources/AgentStudioGitContracts/GitWorktreeForkContracts.swift:445). | Decide Linux node/metadata/name profiles, including what is reproduced, normalized, skipped or refused. The current reason vocabulary is not automatically a Linux policy. |
| Exact metadata versus accepted exceptions | For non-regular nodes, the metadata helper copies xattrs, ACL, mode, access/modification times and selected flags; it reports selected owner/set-ID differences. An xattr write denied with EPERM is accepted if the destination already carries that name, without comparing its bytes in that branch. Symlink target bytes are kept separately from UTF-8 path-name decoding. [Metadata](../../../../../../../agentstudio-git/Sources/AgentStudioGitLocal/WorktreeFork/WorktreeForkEntryMetadata.swift:15), [xattr exception](../../../../../../../agentstudio-git/Sources/AgentStudioGitLocal/WorktreeFork/WorktreeForkEntryMetadata.swift:73), [link text](../../../../../../../agentstudio-git/Sources/AgentStudioGitLocal/WorktreeFork/WorktreeForkLeafWorker.swift:178). | Name the actual equality, accepted exception and reporting rules by field/node/platform. Do not turn a metadata-copy call into universal byte equality, or confuse symlink payload bytes with the filename domain. This is current policy evidence, not a diagnosed defect. |
| Source currentness | Source walking explicitly permits an entry removed after enumeration to be absent. That name is dropped before a plan entry exists and has no per-path disappearance receipt. It rejects undecodable names; separate typed errors cover disallowed source identity/content/repository changes. [Walker](../../../../../../../agentstudio-git/Sources/AgentStudioGitLocal/WorktreeFork/WorktreeForkSourceWalker.swift:175), [report construction](../../../../../../../agentstudio-git/Sources/AgentStudioGitLocal/WorktreeFork/LibGit2WorktreeForkWriter.swift:448), [race errors](../../../../../../../agentstudio-git/Sources/AgentStudioGitContracts/GitWorktreeForkError.swift:130). | Specify allowed mixed-time changes and their reporting coverage separately. “Fork” does not independently promise a point-in-time snapshot or a per-path explanation of every absence. |
| Refusal versus partial work | Errors distinguish rejection, branch use, unsupported working state, Git failure, source change, entry failure, cancellation and validation failure. Cleanup failure wraps the primary error with ordered residue. [Error contract](../../../../../../../agentstudio-git/Sources/AgentStudioGitContracts/GitWorktreeForkError.swift:6). | Preserve effect uncertainty and residue separately from reason/status. A transport error or one Boolean cannot identify which effects remain. |
| Cancellation and rollback | Fork-specific task cancellation is forwarded into the transaction. The call awaits its result; post-mutation failure rolls back before repository-lane custody releases. The journal can report incomplete cleanup. A cancellation arriving after the final check is not guaranteed to replace an already-finished success. [Async owner](../../../../../../../agentstudio-git/Sources/AgentStudioGitLocal/LibGit2AgentStudioGitLocalClient.swift:76), [failure path](../../../../../../../agentstudio-git/Sources/AgentStudioGitLocal/WorktreeFork/LibGit2WorktreeForkWriter.swift:62), [final check](../../../../../../../agentstudio-git/Sources/AgentStudioGitLocal/WorktreeFork/LibGit2WorktreeForkWriter.swift:265). | Specify request cancellation, work completion and cleanup completion separately across the network. No universal cancellation contract for other operations follows from this fork path. |
| Cleanup ownership | The journal distinguishes confirmed created paths from unconfirmed paths, protects refused/foreign artifacts, and compensates branch effects conditionally. Residue includes an unconfirmed branch-move undo; it does not assert the branch's present tip. [Journal](../../../../../../../agentstudio-git/Sources/AgentStudioGitLocal/WorktreeFork/WorktreeForkRollbackJournal.swift:6), [branch residue](../../../../../../../agentstudio-git/Sources/AgentStudioGitContracts/GitWorktreeForkError.swift:176). | Define ownership evidence and current-state readback before cleanup or a repeat. A residue name is not permission to delete a current path or reset a branch. |
| Process loss | The current rollback journal explicitly lives for one call and has no persistence or crash recovery. [Lifetime](../../../../../../../agentstudio-git/Sources/AgentStudioGitLocal/WorktreeFork/WorktreeForkRollbackJournal.swift:24). | Host crash/restart and lost-reply reconciliation remain G3/G8. Joined in-process rollback is not crash recovery, durable intent or automatic-repeat permission. |

The success report is not a census of every name that existed during source traversal. These existing distinctions illustrate its coverage; they are not an exhaustive taxonomy of all reasons destination content can differ:

| Absence or exclusion | Existing report coverage |
| --- | --- |
| Reported socket skip | `skippedEntries` has a relative path and the public `unixSocketNotReproducible` reason. |
| Ignored-path exclusion | `ignoredExcludedCount` is aggregate evidence, not a per-path list of all ignored exclusions. |
| Nested worktree exclusion | `nestedWorktreesSkipped` supplies a separate path list; it is not the socket-skip field. |
| Name vanishes between directory enumeration and entry stat | ENOENT is permitted and the name is dropped before planning, with no per-path report of that disappearance. |

These fields come from the [report contract](../../../../../../../agentstudio-git/Sources/AgentStudioGitContracts/GitWorktreeForkContracts.swift:280), [builder](../../../../../../../agentstudio-git/Sources/AgentStudioGitLocal/WorktreeFork/LibGit2WorktreeForkWriter.swift:448) and [enumeration branch](../../../../../../../agentstudio-git/Sources/AgentStudioGitLocal/WorktreeFork/WorktreeForkSourceWalker.swift:189). Whether the counterpart reports additional per-path disappearance evidence remains an open contract choice; no more detailed receipt is selected by documenting this baseline.

## Contract slots to close before Linux parity can be accepted

These are missing definitions under the existing Specification gaps, not additional selected defaults.

| Slot | Meaning the complete contract must provide | Existing gap |
| --- | --- | --- |
| W1 — Capability and entry scope | Selected fork/create/eligibility surfaces, standalone CLI availability and allowed frontend options. Preserve the required Gateway route. | G1/G8 |
| W2 — Identity and locations | Repository/worktree/attempt identity, Host-qualified source/destination, configuration/archive/result locations and allowed path/name domain. | G7/G8/G9 |
| W3 — Capture and concurrency | Captured HEAD/index/content boundary, allowed mixed-time changes and whether their disappearance is reported, branch expected-tip/use fences and conflicts with other writers. | G7/G8 |
| W4 — Materialization | Preserved CoW/changes-only/checkout semantics, start/reset behavior, ignored-path policy and explicit availability/refusal. | G1/G7 |
| W5 — Filesystem profile | Supported Linux filesystem/kernel/environment and same/cross-device rules, plus regular-file CoW evidence. A primitive probe covers only its named leaf. | G7/G12 |
| W6 — Fidelity | Directory/file/link/hard-link/special-node treatment; symlink payload bytes; mode/owner/ACL/xattr/flags and selected timestamp fields; which differences are reported per path, counted, intentionally unreported or refused. | G7 |
| W7 — Git topology | Main/linked and nested repository/submodule administration, alternates and configuration-include closure, HEAD/index/sparse/conflict/reset/LFS behavior and independent usable-result observation. | G7 |
| W8 — Outcome and cleanup | Typed success/refusal/primary failure/residue and receipt-coverage limits, platform-native detail separated from public reason, cancellation after each effect boundary, ownership-preserving cleanup and authoritative remaining-state observation. | G7/G8 |
| W9 — Lost connection and restart | Distinguish lost response from known non-execution; select any retention/reconciliation/restart promises explicitly. No automatic replay follows from the current package call. | G3/G8 |
| W10 — Client observation | Which results/facts each client receives; discovery/publication/native readiness and event currentness distinct from package success. | G8/G9 |
| W11 — Engineering and performance | Safe first-party Rust/Tokio realization, dependency/FFI safety scope, meaningful interaction tests and measured workload/resource acceptance. No backend or numerical bound is selected here. | G10/G11 |

## Discriminating behavior evidence

The future proof uses the complete selected contract on both Host platforms. The [Linux feasibility procedure](../experiments/linux-feasibility.md) remains a leaf/environment discriminator; it cannot close W1–W11 or the full V2 obligation.

| Scenario | Independent observation needed | What a weaker check misses |
| --- | --- | --- |
| Fork accepted after an earlier available hint | Actual admission and resulting Git/filesystem state, with a branch/source change between hint and execution | Eligibility is not a reservation or approval of the full request. |
| Successful fork with admitted differences | Usable HEAD/index/branch/nested state plus exact selected skipped/normalized/excluded evidence | Equal file counts or visible success can hide wrong data, metadata or administration. |
| Name vanishes after enumeration but before entry stat | Controlled source mutation at the actual enumeration/stat boundary; compare the result's promised reporting level independently | A successful fork and a socket-skip list do not establish a per-path census. Current mixed-time disappearance is unreported; no stronger target receipt is implied. |
| Competing branch/path writer | Current branch and path identity at the real effect/cleanup boundary, including a foreign replacement | Path existence or the original planned ref does not establish present ownership. |
| Cancellation during materialization | Exact cancellation request, completed workers/rollback and remaining artifacts before the next scoped mutation | A cancelled network future is not evidence that native work and cleanup have ended. |
| Rollback failure | Primary error plus independently inspected destination/admin/branch/lock residue | An error response does not mean zero effects. |
| Lost response or Host process loss | Independently identified actual work/effects and any selected reconciliation/recovery outcome | Retrying a fresh request or reopening a socket does not prove the first attempt failed. |
| Native and CLI parity | Each selected entry's actual options/effect/result, plus client publication/readiness where promised | A package fixture alone does not exercise frontend policy or the service route. |

Current source examples include [ordered cleanup residue and preservation of a foreign destination](../../../../../../../agentstudio-git/Tests/AgentStudioGitTests/Integration/GitWorktreeForkRollbackIntegrationTests.swift:239) and [rollback before the next repository mutation](../../../../../../../agentstudio-git/Tests/AgentStudioGitTests/Integration/GitWorktreeForkRollbackIntegrationTests.swift:317). These test bodies were read, not run. No full Linux realization or counterpart behavior is established.
