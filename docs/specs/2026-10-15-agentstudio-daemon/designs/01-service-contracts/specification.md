## K13 — Protocol, streams and resource admission

**Consumer / entities / basis:** frontend and service integrator; E3/E4/E19/E20/E23/E24; U1–U3/U9/U17/U18/U19, R1/R3/R7/R11–R13. Frontend access is UX clients → declared local Gateway entry → macOS/iOS Gateway → attached Host. S32 assigns browser content to loopback HTTP/WebSocket and selected native bootstrap/control to macOS UDS or embedded iOS FFI. Eligible Host-local CLI and authorized session inputs use R9/R12 locally. IP3 sends machine-scoped worktree CLI to its attached local Host daemon and selects local activation when absent; UX/frontend CLI remains on the Gateway route. Non-session attachment discovery and authority remain G1/G8/G12; process location alone cannot select a target or fallback. Same-machine IPC and cross-machine network admission differ.

One Host supports multiple Mac Gateways; one Gateway supports multiple remote Hosts. Every request, subscription, result and terminal view preserves its target Host context. One unreachable Host does not make another’s valid operation unavailable. Host identity and authority cannot be inferred from equal paths, session labels or socket counts. Numeric limits, attach/detach trust, selection UX and any cross-Host aggregate partial-result contract remain G2/G8/G9/G12.

Control request/reply, ordered domain facts, replaceable state, terminal VT bytes and finite content have different semantics. A multiplexed transport must not turn loss/overflow into silent arbitrary VT-byte loss, block required Host fact collection behind a slow viewer, or confuse subscription lifetime with execution lifetime. Bounded resource and slow-consumer behavior must be explicit; resnapshot versus detach/gap refusal remains G6/G8. Reliable transport alone does not establish ordered snapshot/live restoration or input replay safety.

Current app protocol is NDJSON/JSON-RPC with no batches, distinct request/response/frame/write limits and channel/catalog gates. Current request 1 MiB, response/notification 16 MiB and writer queue 4 MiB bounds are baseline observations, not adopted target constants; a frame-valid result can still fail writer admission. Enqueued/delivered does not mean peer processed. Exact new size/queue/stream/deadline/version/capability profiles remain G8/G10/G12.

S32 selects upstream Quinn QUIC for the remote Gateway/Host leg; it is not a measured performance winner. Browser content uses same-origin loopback HTTP/WebSocket and native macOS control uses UDS. S32 selects an embedded iOS Gateway with native bootstrap/control through FFI; the exact binding must satisfy U10 and qualify on the physical device. RPC semantics, codec/compression, schema generation and supported versions remain separate decisions. Earlier quic-rpc/iroh-quinn and Tonic comparisons are research history, not selected dependencies. MCP remains an intentional external subset adapter, not the internal protocol or an automatic exposure of every privileged operation. The [bounded transport design](../../increments/00-qualification/bridge-gateway-transport/index.md) owns the S32 refinement.

R13 requires one authoritative schema contract with derived or validated cross-language shapes. Cover every selected method, response/event/error/frame variant and semantic rejection with real Swift and Rust Gateway processes over Unix sockets, plus fragmented/coalesced frames, declared limits, supported version pairs, incompatible-pair refusal and interrupted traffic. Rust Gateway↔Host network compatibility is separate. This chooses no generator, codec or supported version matrix.

**Proof:** real whole-route allowed/refused input, malformed/oversized and post-submit unknown cases, independent concurrent terminal/control/content traffic, bounded slow subscriber behavior, reconnect/version mismatch and actual supported devices. Same-process codec roundtrip does not prove these. K5/K9 define terminal/content correctness; performance observations must distinguish local IPC RTT, remote RPC RTT, key-to-visible echo, throughput, memory and reconnect-to-render. Workloads/acceptance bounds are G10; current source suggests no measured regression or universal sub-millisecond claim.
