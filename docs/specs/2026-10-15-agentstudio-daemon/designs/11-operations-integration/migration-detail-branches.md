# Smaller branches inside the migration map

**A broad feature home is not enough to preserve every path inside it.** These named branches refine the [42-leaf feature checklist](migration-feature-checklist.md) and its existing command/data maps. They remain unchecked until their own selected contract, integration and proof boundary is met. Supporting code and dormant declarations are accounted for without becoming new public features.

The whole path remains high-level. Near-term launch/control/source contracts belong in the [remote-session slice](near-term-migration.md); later native, browser, approval and Git details become concrete when their capability is selected. This adds neither a twelfth subsystem nor an independent crate for each row.
