## Missing versus explicit null

| Location | Source-observed current behavior |
| --- | --- |
| Envelope: neither non-null result nor error | Both readers reject. Missing result and result:null with no error both reach this case. |
| Envelope: non-null result and non-null error | Both reject. |
| Envelope: one non-null side plus other key:null | Null side counts absent; exclusivity is on non-null values, not key existence. This branch was not executed or found as a dedicated fixture here. |
| Envelope id or error.data | Optional decoding collapses missing and explicit null to nil. Encoder can still represent JSONRPCIdentifier.null. |
| Required pane counter | Missing rejected by required schema; null rejected by nonnullable integer schema/custom decode(UInt64). |
| Optional context title/line/session/truncation | decodeIfPresent makes missing/null nil; encodeIfPresent omits nil. .optional schema allows omission or null. |
| Typed optional normalization | Input null can become omitted after typed re-encoding; static composition inference described below. |

source: Generic response model uses decodeIfPresent for id/result/error. Discovery header uses contains(result) plus decodeNil, then the same exclusive-value validation. Thus a raw result:null success can be composed by the encoder API but is rejected by both readers as the sole success value. This is a source counterexample to universal nullable-result support, not a measured current-method incident. ([Generic response](../../../../../../Sources/AgentStudioIPCTransport/JSONRPCCodec.swift:193), [encoder success API](../../../../../../Sources/AgentStudioIPCTransport/JSONRPCCodec.swift:177), [discovery header](../../../../../../Sources/AgentStudioIPCTransport/JSONRPCCodec+DiscoveryResult.swift:42), [shared validation](../../../../../../Sources/AgentStudioIPCTransport/JSONRPCCodec+DiscoveryResult.swift:31).)

source: Optional context fields explicitly use decodeIfPresent/encodeIfPresent. Schema optional means optional presence plus oneOf(value,null); required/optional/default handling is distinct. ([Context Codable](../../../../../../Sources/AgentStudioProgrammaticControl/IPCPaneContextReadContracts.swift:161), [optional helper](../../../../../../Sources/AgentStudioProgrammaticControl/IPCSchemaProviding.swift:30), [presence normalizer](../../../../../../Sources/AgentStudioProgrammaticControl/IPCJSONSchema.swift:333).)

inference: An explicit-null optional context field can be canonicalized to omission through descriptor.normalizeResult: typed nil re-encoding omits it; comparison permits input-null/output-missing; changed typed representation is then normalized. This is a static composition consequence, not a measured output or selected future policy. ([Comparison](../../../../../../Sources/AgentStudioProgrammaticControl/IPCJSONSchema+TypedEncoding.swift:41), [normalization](../../../../../../Sources/AgentStudioProgrammaticControl/IPCMethodContract.swift:112), [changed representation](../../../../../../Sources/AgentStudioProgrammaticControl/IPCMethodContract.swift:155).)
