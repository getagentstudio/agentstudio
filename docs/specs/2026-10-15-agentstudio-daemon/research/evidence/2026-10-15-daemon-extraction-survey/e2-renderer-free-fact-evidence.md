## Independent comparison boundary and missing evidence

A present/absent arm needs the same declared source stimulus, owning host/session/process incarnation and exact semantic checkpoint. Observe source production, admitted disposition, committed owner state, publication and later client reconciliation separately. A declared backend Info closure is only that boundary; a source write return or arbitrary sleep does not establish parsed-cut/application completion. E1's protocol/cut procedure is reused, not reproved here.

Required negative discriminators already follow from current behavior: a swallowed/too-long title must not count as an observed title transition; equal CWD may suppress publication while native work still runs; output bytes without row growth must not masquerade as the same activity population; quiet promotion must be revocable; a stale command exit must not end a successor; an ignored/recordOnly hook must not be mistaken for live status or hook activity; attach death must not stand for backend shell death. Compare each against hand-declared expected values and scope, not a common formatter/hash or the same reducer on both sides.

Current source does not provide a complete app-absent fact-capture/recovery witness or a current backend→semantic title/activity/provider feed. Renderer-free source capability, production of a fact, retained fact history, Swift publication and rendered output are distinct claims. No retention/restart guarantee, new persistence or extra signal follows from this gap. [U15](../../../user-requirements.md:38) remains an obligation; [U17](../../../user-requirements.md:40) still requires client → socket → Gateway → Host. Authorized agent input during Gateway loss versus that route remains explicitly unresolved; no direct-Host bypass/spool is inferred.
