## Result and bounded lane inventory

Current Swift has both a shared typed EventBus and scoped owner paths. A comparison cannot use shared bus versus scoped ownership as if they were mutually exclusive current architectures. Raw source admission, direct controls, local presentation, admitted coordination facts, and display application are distinct responsibilities.

The consumer contracts to preserve are coherent state, explicit currentness, equality/revision behavior, admitted ordering, native application, and honest loss/resource accounting. Existing class topology is not an extraction requirement. MainActor remains the current native publication/application boundary; its annotation does not establish that all current derivation/scheduling belongs there.

## Normative contract versus source evidence

[Input classification](../../../../../architecture/state/demand_driven_derived_state_refresh.md:8) distinguishes ordered facts, latest state, bursts, expensive refresh, and future deadlines. Its nine stages are responsibilities, not nine types/hops. [Suppression and deferral gates](../../../../../architecture/state/demand_driven_derived_state_refresh.md:92) require different oracles: sequence-end equality versus equality at the first demanded checkpoint. Cancellation/timeout/unobserved work is not equality.

[Atom selection](../../../../../architecture/state/atom_persistence_boundaries.md:9) begins with a subscriber, not a table. Keyed observation, cheap derived readers, runtime/presentation state, durable state, and row projections are separate. [Actor placement](../../../../../architecture/state/atom_persistence_boundaries.md:257) allows compact Sendable outcomes back to MainActor rather than moving expensive joins/I/O there.

[Typed admission](../../../../../architecture/runtime/pane_runtime_eventbus_design.md:75) contracts terminal samples before bus multiplexing. [Hop shape](../../../../../architecture/runtime/pane_runtime_eventbus_design.md:211) says MainActor/bus volume should follow drains and changed outcomes. The concrete caveats below are current-source limits, not requests to repair or preserve debt.

## L1 — Latest title, exact barrier, and changed publication

**Input and admission.** [Native ingress](../../../../../../Sources/AgentStudio/Features/Terminal/Ghostty/GhosttyActionRouter+NativeIngress.swift:7) decodes/copies payload and stable surface/view identity before returning from the C boundary. [Disposition](../../../../../../Sources/AgentStudio/Features/Terminal/Ghostty/GhosttyActionDisposition.swift:41) classifies title/tab title as latest semantic metadata. [Admission](../../../../../../Sources/AgentStudio/Features/Terminal/Ghostty/GhosttyActionRouter+LocalActions.swift:48) sends them to the accumulator rather than raw bus publication.

**Contraction and scheduling.** [Publication state](../../../../../../Sources/AgentStudio/Features/Terminal/Ghostty/TerminalLocalActionAccumulator.swift:17) distinguishes unknown, pending with last committed, and committed. Acknowledging old A while B is pending preserves B. [Offer](../../../../../../Sources/AgentStudio/Features/Terminal/Ghostty/TerminalLocalActionAccumulator.swift:165) holds independent title/immediate lanes, one fixed deadline from first title offer, and latest replacements. [Scheduler](../../../../../../Sources/AgentStudio/Features/Terminal/Ghostty/TerminalLocalActionDrainScheduler.swift:121) owns tokenized claims, title deadline, one MainActor drain, and bounded follow-up claim. [Exact barrier](../../../../../../Sources/AgentStudio/Features/Terminal/Ghostty/TerminalLocalActionAccumulator.swift:255) detaches preceding title before routing an exact control/fact.

**Apply and endpoint.** [Compact apply](../../../../../../Sources/AgentStudio/Features/Terminal/Ghostty/GhosttyActionRoutingHost+LocalActions.swift:34) resolves the mounted surface lifetime, updates native surface title only if unequal, routes latest runtime title, and acknowledges successful routing. [Exact apply](../../../../../../Sources/AgentStudio/Features/Terminal/Ghostty/GhosttyActionRoutingHost.swift:144) applies preceding title before the exact event. [Runtime](../../../../../../Sources/AgentStudio/Features/Terminal/Runtime/TerminalRuntime.swift:284) compares stored title, updates metadata, and emits only changed title. [App consumer](../../../../../../Sources/AgentStudio/App/Coordination/WorkspaceSurfaceCoordinator.swift:702) updates the source pane title after live tab membership admission.

**Proof and limit.** [Publication sequence tests](../../../../../../Tests/AgentStudioTests/Features/Terminal/Ghostty/TerminalPublicationStateTests.swift:10) manually drive unknown/equal/replacement/A-B-A/ack race/failure/retirement cases and compare final published title to a reference. [Absolute deadline test](../../../../../../Tests/AgentStudioTests/Features/Terminal/Ghostty/TerminalLocalActionAccumulatorTests.swift:53) injects nanosecond time; it does not sleep to prove correctness. These test contraction/scheduler seams with injected application, not real Ghostty or full bus/pane rendering.

**Independent oracle seam.** Compare expected title at each declared exact barrier and at sequence end against native title, runtime metadata and consumer pane title. Count actual revision/envelope changes separately from accepted routing. A changed-title negative control must alter one of those expected values.

**Current telemetry caveat.** Compact apply sets its changed outcome when title routing returns accepted, while runtime may suppress the already-equal metadata. Thus that apply-outcome counter alone is not proof of an actual metadata write or bus event.

## L2 — CWD admission, native cache, and pane association

**Input and two branches.** The same copied CWD input first queues a [native working-directory update](../../../../../../Sources/AgentStudio/Features/Terminal/Ghostty/GhosttyActionRouter.swift:53), then runs runtime admission. **Native branch.** [Native apply](../../../../../../Sources/AgentStudio/Features/Terminal/Ghostty/SurfaceManager+CallbackRouting.swift:39) validates surface/view lifetime and calls `pwdDidChange`. [The native property](../../../../../../Sources/AgentStudio/Features/Terminal/Ghostty/GhosttySurfaceView.swift:313) suppresses equal value before scheduling its changed callback. [SurfaceManager](../../../../../../Sources/AgentStudio/Features/Terminal/Ghostty/SurfaceManager.swift:759) normalizes and equal-suppresses managed-surface metadata, then yields a higher-level surface CWD stream.

**Runtime/domain branch.** [Exact routing](../../../../../../Sources/AgentStudio/Features/Terminal/Ghostty/GhosttyActionRoutingHost.swift:167) acknowledges success or records failed CWD publication. [Runtime](../../../../../../Sources/AgentStudio/Features/Terminal/Runtime/TerminalRuntime.swift:289) equal-suppresses metadata and emits changed CWD. [App consumer](../../../../../../Sources/AgentStudio/App/Coordination/WorkspaceSurfaceCoordinator.swift:706) normalizes shell CWD, then [reserves an association revision](../../../../../../Sources/AgentStudio/App/Coordination/WorkspaceSurfaceCoordinator.swift:444), resolves topology, applies association, rejects stale revisions, and updates affected filesystem context/zoom companion only for applicable outcomes.

**Proof and limit.** [CWD publication test](../../../../../../Tests/AgentStudioTests/Features/Terminal/Ghostty/TerminalPublicationStateTests.swift:161) proves failure retry, normalized committed equality and lifetime reset at accumulator level. It does not cover the native branch or complete association/UI result. Search for `surfaceCWDChanges` in product sources found its declaration/accessor but no product consumer; that stream alone is not proof of canonical pane publication.

**Independent oracle seam.** After correlated existing owner completion, compare declared normalized CWD and repo/worktree identity against runtime metadata and composed pane association; separately inspect native managed-surface metadata. Replaced surface IDs and stale association revisions must fail to affect the successor.

**Current hop caveat.** Equal raw CWD still queues the first native MainActor update before the runtime equality gate. Runtime source suppression therefore does not establish zero MainActor work for equal raw CWD.

## L4 — Search lifecycle is local and epoch-bound

[Disposition](../../../../../../Sources/AgentStudio/Features/Terminal/Ghostty/GhosttyActionDisposition.swift:43) separates latest search counts/selection from exact local start/end. [Accumulator admission](../../../../../../Sources/AgentStudio/Features/Terminal/Ghostty/TerminalLocalActionAccumulator+Admission.swift:49) advances search epochs, clears stale pending presentation, rejects inactive-search values, and retains a fixed lifecycle summary. It uses the immediate drain; it does not turn each lifecycle item into a globally replayable fact.

[MainActor application](../../../../../../Sources/AgentStudio/Features/Terminal/Runtime/TerminalRuntime.swift:200) applies start/end state, accepts counts only at the current local epoch and while search exists, and equal-suppresses counts/selection. This path explicitly allocates no envelopes, advances no event sequence, writes no replay, and posts to neither pane nor global bus.

[Barrier test](../../../../../../Tests/AgentStudioTests/Features/Terminal/Ghostty/TerminalLocalActionAccumulatorTests.swift:496) offers start/count/selection/end followed by late values and expects inactive state with no search update. Further cases test across-drain epochs and lifetime reset. These are accumulator tests, not native search rendering.

**Independent oracle seam.** Compare final local search state/epoch against an explicit start/end trace, including late old-epoch counts. Corroborate that runtime event sequence/replay/bus publication did not increase for this local-only path. A bus implementation that publishes every raw search sample is not behaviorally equivalent merely because its last visible count matches.

## U15 app-absent and Host-fact gaps

`U15` explicitly requires sessions, authorized agents, terminal facts/activity while Swift is closed or Gateway disconnected. That authorized outcome is not reopened here. Current source does not establish it:

- Title and CWD enter through app-owned Ghostty callbacks and mounted-surface/runtime mapping. Local publication acknowledgements are not renderer-free Host observations.
- Current activity depends on scrollbar evidence, native viewport text, attention/context and local surface lifetime. The literal line/equal-line behavior cannot be equated to raw backend bytes, transcript semantics, or a generic Host activity timestamp.
- Command-finished already has an exact local settle before lossy bus delivery, but still originates in the app Ghostty path. Sessions' app consumer receives its own fact downstream; no no-client fact implementation was established by this trace.
- Native visibility/demand controls useful expensive refresh and materialization. Absence of client demand is not authority to stop the Host work required by `U15`; nor is it authority for unlimited background work or history.
- Local revisions, ContinuousClock instants, surface/view identities, view incarnations and session operation IDs have current in-process meanings. This report proves no cross-process clock, recovery, persisted history or shared-layout contract.
- Agent CLI requests must retain client → socket → Gateway → Host routing. No direct Host bypass or spool is inferred to reconcile the disconnected-input question.

The missing proof is an app-absent reference for the selected Host fact meanings plus currentness/recovery evidence through the mandated route. This report does not choose an extra terminal parser/VT, transcript store, bus topology, or retention mechanism to fill that gap.
