## Concrete counterexamples to overbroad claims

1. **“Available guarantees a forkable Git source/destination.” Refuted by direct control flow, not executed:** changes-only eligibility resolves a source directory and destination parent, checks overlap, then returns available without opening a repository or checking destination existence. An existing non-Git source directory and valid nonoverlapping destination-parent can therefore satisfy this query while fork's exact Git capture rejects. CoW availability also omits Git topology/tree and destination existence. [Eligibility][eligibility], [full capture][git-capture].
2. **“Successful CoW means every source node and attribute is identical.” Refuted by public receipt:** skipped sockets and normalized owner/group/setid loss are representable successful evidence; reset deliberately leaves work in progress out and can report submodules not at start. [Report/loss vocabulary][report], [loss kinds][loss-kinds]. Exact leaf emission conditions remain uninspected here.
3. **“A failure always leaves nothing.” Concrete existing test body:** inject failure after materialization and separately fail destination cleanup; assert cleanupIncomplete(primary=injected,residue=[destinationContent at `.`]), destination still present, administration absent and original branches unchanged. [Test:239][test-residue]. Another test creates a foreign destination after planning; failed add leaves unconfirmed destination/admin as residue without deleting them, empty or nonempty. [Test:271][test-foreign]. These are inspected assertions, not current green results.
4. **“Cancellation immediately releases the lane.” Concrete existing test body:** a leaf remains held after task cancellation until explicitly released; test awaits fork result, checks cancelled and exact event order `[rollbackFinished,nextMutationRan]`, plus absent owned destination/admin. [Test:316][test-cancel]. The source therefore requires physical worker/compensation custody; no wall-clock latency bound is established.
5. **“Rollback restores arbitrary pre-call state / survives process death.” Refuted by current journal:** it compensates only recorded owned/conditional effects and deliberately has no persisted recovery. Foreign locks/replacements can be protected and retained; unsupported system-flag cleanup can fail. [Journal:24][journal], [protected cleanup][cleanup]. No arbitrary writer's state is globally rolled back.

Additional inspected test bodies: phase-by-phase injected failure for new/detached modes; failure while HEAD is attached under branch lock for new/existing-fast-forward modes; cloned deny-delete ACL cleanup with unchanged source ACL; owned lock residue retaining confirmed ancestor artifacts; queued cancellation before mutation. [Phase:99][test-phases], [attach:143][test-attach], [ACL:189][test-acl], [lock residue:15][test-lock], [queued:383][test-queued]. No test suite was run and fixture/helper internals were not independently audited as extra units.
