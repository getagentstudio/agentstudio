One system, clear owners

AgentStudio combines terminal control, native agent control and the existing machine features. The useful distinction is who owns each operation and truth, followed by which owners share a process. This reader explains the research; it is not a claim that the Rust integration is built.

The owning Router design now records reusable execution behind distinct native, MCP and ACP adapters, with proposed cancellation ownership and reply contracts. The checked reuse map and update separates those design choices from implemented behavior and the remaining daemon proof.

Active agent turns must keep running through a planned Host upgrade. Independent execution custody must be qualified. Restoring a conversation after interrupting its turn does not satisfy that outcome.

Both standalone and board-linked delegation are supported, with durable execution tracking in either case. A saved board task is optional.

What the Gateway prepares

The Gateway can combine authorized source observations into repository groups, session status, context summaries and search results. It carries source validity and the current client intent. The Host still performs authoritative work; the native client still establishes actual viewing and rendering.

A stale or missing source must remain stale or unavailable. Two Hosts with the same path are still different resources. Receiving a row does not authorize a mutation or mark a person as having viewed it.
