# I2 — Autonomous agents, facts and retained context

The usable outcome is that supported Codex/Claude integration and authorized context work continue on the executing Host with Swift closed and every Gateway (macOS or iOS) unavailable. Basis: U4/U9/U13/U15, R9/R10/R15/R16; domain contracts K5/K7/K8/K14. E1 execution, E9 provider conversation, E10 binding, E11 message and E16 client view remain separate.

| Feature slice | Host-owned contract | Client and failure boundary |
| --- | --- | --- |
| Provider installation/hooks | Declared machine/provider/configuration root; provider-specific projection and admission | Installed files are not provider trust; hook exit zero is not accepted Host evidence |
| Provider conversations/bindings | Provenance and current generation admitted with the owning transaction | Old binding cannot become current through reconnect or pane recreation |
| Title/line/activity/facts | Declared semantic sources, source lifetime and ordered-versus-latest meaning | Renderer absence is observed; byte counters/quiet heuristics are not silently substituted |
| Notices/asks/answers | Retained scoped identity, exact settlement and transactional state | Human reading, delivery acknowledgement, retained answer and agent action remain distinct |
| Writer claim/order | Host binding plus producer claim/epoch/counter contract | Lost response/restart follows declared duplicate/reconciliation policy, not blind retry |
| Context query/change delivery | Audience, cursor/coverage and retained-history meaning | Gap/unestablished coverage is explicit; native views are readers/interaction targets |

Current integration runs provider projection in IPCClientCore and joins Sessions/context in App composition over a local transaction port. Target integration moves authoritative admission/retained workflow to the Host while Swift gets prepared display/interaction state. Preserve binding/context/intake-cursor atomicity; private producer state is not automatically deleted or exported.

Complete the exact public method mapping, supported provider resources, Host-session credential/scope/revocation, fact/history/restart and G13 write-availability profiles. Current notice-only offline machinery is baseline, not a required generalized spool. IP3 selects worktree machine CLI → attached local Host daemon with start/activation when absent; authorized session work remains local and UX/frontend CLI retains Gateway access. Exact startup/readiness/failure, discovery and admission remain G1/G8/G12.

Prove real provider-shaped Host-local inputs, stale/revoked/wrong-session refusal, binding-at-commit races, all selected fact witnesses while app/Gateways are absent, retained ask/answer/withdraw/deadline/EOF outcomes and client reconciliation. A socket test or a surviving shell alone is insufficient. This profile contributes the remaining U15 promise rather than redefining it.
