# I5 — Remote reviews, annotations and actual output destinations

The usable outcome is remote file/review products and retained annotation workflows consumed by AgentStudio, including explicit client/native/file output. Basis: U3/U4/U9/U13; K9/K10/K12 and R15/R16. This includes sixteen surveyed Bridge semantic calls and twenty-two nested annotation operations as overlapping vocabularies, not an additive new public API count.

| Slice | Authoritative work | Native/client boundary |
| --- | --- | --- |
| File/review construction and refresh | Host constructs source-bound products and finite content | Swift/BridgeWeb install/apply/render; provider completion is not presented pixels |
| Annotation sessions/threads/messages | Host saved revisions, anchors, source-currentness and workflow transactions | Draft/edit interaction stays distinct from committed saved text |
| Prepared output | Exact saved revision membership, immutable bytes/destination/attempt | The real declared client or machine performs clipboard/file/native effect |
| Finalization/history/repeat | Host updates attempt/event/handled-membership/session revision atomically | Effect may have happened before failed finalization; repeat unknown is a new attempt, not proof old failed |

Current product/annotation actors and native scheme delivery are separate from construction and output effects. S32 replaces the target per-chunk Swift scheme relay with [direct browser/Gateway loopback delivery](../00-qualification/bridge-gateway-transport/index.md); current scheme code remains the observed baseline until its strangler slice lands. Target changes the backend/control boundary, not every React/native component into Rust. Host annotation workflow retains its real atomic predicates; native output is outside SQL and must report its own result back through the declared operation.

Select content/range/kind/version/limit and source-refresh contracts, edit ownership, destination audience/consent/location and retained recovery/history profile. A Host path is not a local file URL. Copying output-attempt rows never means replaying the business effect.

Prove source bytes/revision races through real supported worker/native viewers, exact prepared membership and bytes, destination cancellation, clipboard partial mutation, exclusive-file residue, known effect plus failed Host finalization and uncertain recovery/repeat. A hash, HTTP response, callback or generic successful wrapper alone does not close the feature.
