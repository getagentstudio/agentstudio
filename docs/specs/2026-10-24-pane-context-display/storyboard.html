Rules applied

  • Input facts determine status, Agent Line and counts on each surface → O1
  • Brackets only on Agent Line ages; other ages plain; 220/360 pt text clamps → O2–O3

  • An unbound pane can still show its known pane-written line and notices → O5
  • Sidebar lines: title, status, Agent Line, chips; absent lines leave no gap; no dividers; drawer source labels preserved → O7–O8
  • Toolbar: notes divider, then all item chips while unread items or open asks exist, otherwise the Agent Line; empty hides the divider → O11, O20
  • Compact activity chips without a line; plain ACTIVE ages on the card → O13, O33
  • Show the actual answer form, or where to answer a provider prompt → O31–O32
  • Full bodies, source labels, exact Resolved states, all returned prompts and pinned footer → O40–O43
  • Full Agent Line text, age, writer and Go to pane → O50
